# Odin Recipes

This project was created as part of **The Odin Project** curriculum (Foundations course).

## Description
This project is a simple recipe website. The main goal is to practice basic HTML skills and development tools.

## Skills & Demonstrated Knowledge
Upon completing this project, I will demonstrate the ability to:
* Work with basic HTML5 structure.
* Use core elements like headings (`<h1>`–`<h6>`), paragraphs (`<p>`), lists (`<ul>`, `<ol>`), and links (`<a>`).
* Embed and display images (`<img>`).
* Manage project versions with **Git** and push changes to **GitHub**.
* Organize a web project's file structure.
